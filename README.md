# ProjectM - Kart Racing Game Prototype

## 개요
ProjectM은 **Unreal Engine 5 (테스트 기준: 5.4)** 기반으로 만든 카트 레이싱 게임 프로토타입입니다. 언리얼 엔진 기반 카트 레이싱 게임으로 차량 물리 및 네트워크 동기화를 구현했습니다.

## 주요 기능 (예상/기초)
- **카트 조작**: 가속, 감속(브레이크), 좌우 조향을 통한 차량 주행.  
- **트랙 주행**: 정해진 트랙을 따라 주행하면서 랩 타임 또는 구간을 측정할 수 있는 구조.  
- **랩/시간 표시**: 현재 주행 시간 또는 랩 수를 실시간으로 확인할 수 있는 간단한 UI (확장 가능).  
- **물리 기반 움직임**: 언리얼의 물리 엔진을 활용한 자연스러운 차량 피드백.  
- **확장성**: AI 상대, 아이템/부스터, 트랙 변경 등을 추가할 수 있도록 구조화 가능.
